# Security and privacy

Report vulnerabilities privately through [GitHub security advisories](https://github.com/cognia-labs/cognia-browser-extension/security/advisories/new). Do not include live pairing codes, device keys, captured private pages or access tokens in public issues.

In local mode, capture, inspection, editing, prompt copy and Markdown export run without a Host connection. Choosing local mode stops the worker's Host socket and polling, cancels pending operations and disables agent mode while retaining pairing credentials. Reconnecting does not automatically re-enable agent mode. Capturing a page, reading its supported transcript or fetching a chosen attachment can still access that page's own sources through the browser's permission checks.

After pairing, explicitly sending a task uploads captures and attachments to the selected Cognia Host. The Host's configured providers and delivery targets determine any later processing. Pairing uses origin-bound device credentials and DPoP proofs; private keys are generated in the browser. Captured drafts and task sessions use browser session storage. Pairing metadata, local-mode selection, preferences, saved prompts and persistent site decisions use local storage. Those stores retain their existing versioned keys across this extraction.

Broad page access is optional. The capture panel offers a one-time all-sites grant for local tools; this does not enable agent mode. Access is checked against Chrome's actual permissions, and the browser's extension settings can change or revoke it. Disabling agent mode preserves an all-sites grant explicitly requested for local tools; grants requested only by agent mode are still removed. Agent mode additionally requires a Host connection and drive grant, the agent mode switch, compatible protocol/overlay and site approval. Stop and Take over cancel pending work and retain a pause until explicit Resume. Browser APIs already dispatched before cancellation cannot be recalled. Revocation and reconnect behavior is covered by unit and Chromium tests, with Host authorization fences tested by the product's Rust suite.

Incognito is disabled. Do not broaden install permissions, weaken origin checks, bypass cancellation or enable arbitrary page-origin permission messages to simplify tests. Release testing must include native permission refusal and installed-profile/signing identity compatibility.
